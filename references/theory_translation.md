# 形成机制翻译规范

> 本文件是 Dream-IEA Step 2b 的翻译规范：基于梦境形成机制的翻译逻辑——体验域映射、组合体验域合成、情绪匹配、收敛检查、输出格式。

---

## 一、梦境形成机制（理论地基）

### 核心机制

梦境形成 = **情绪驱动的素材选择** + **半随机叙事合成**

三个环节：

| 环节 | 做什么 | 信号还是噪声 |
|------|--------|------------|
| 生成器 | 大脑在睡眠中持续产生内部激活（无外部输入） | — |
| 素材选择 | 情绪系统为高情绪强度的记忆/回路投票，优先回放 | **信号源** |
| 叙事合成 | 把被选中的激活编织成连贯体验，但现实检验下线 | **噪声源** |

### 关键推论

1. **图式频率/共现是信号**：哪些图式出现、多久一次、跟什么组合——反映哪些体验域在清醒生活中被反复激活
2. **叙事结构是噪声**：出场顺序、因果逻辑、时空跳跃——编辑下线后的混沌编织，不作为分析依据
3. **情绪是选择信号**：图式上附着的情绪不是"附加信息"，而是选择信号本身——哪个情绪系统在为这个回路投票
4. **衰减失败 = 处理卡住**：正常情况下情绪强度随回放衰减；不衰减 = 创伤性卡住

### 为什么意象图式是正确的中间层

大脑在没有外部输入时自己生成内容，用的是最底层的建筑模块——即意象图式（源自身体经验的认知基元）。图式高频出现 = 对应体验域的回路在清醒生活中被反复激活。这不是象征翻译，是形成机制的直接推论。

## 二、翻译链（操作层）

```
梦境文本
  ↓ Step 1: 扫描信息元素（七类，原子单位）
  ↓ Step 2a: 从元素中识别意象图式 + 统计
  ↓ Step 2b: 翻译
      输入：图式（体验域方向）+ 情感元素（驱动情绪）+ 其他元素（具体语境）
      操作：体验域映射 → 体验域合成 → 情绪匹配 → 语境填充
      输出：什么样的清醒体验会同时激活这些体验域且匹配这个情绪
```

**理论段**（神经回路 → 图式 → 体验域）是地基，解释为什么这套逻辑成立。
**操作段**（图式+情绪 → 体验域 → 清醒体验）是 AI 实际执行的翻译，完全基于文本可提取的信息。

## 三、体验域映射表

每个意象图式对应一个**体验域**——基于身体经验的体验类别，可从文本中语义识别。

| 意象图式 | 体验域 | 身体起源 | 清醒心理操作 |
|---------|--------|---------|------------|
| **CONTAINER** | 进出/包容/排斥/束缚/自由 | 身体作为容器，进出的经验 | 归属/排斥、束缚/自由感 |
| 容器破裂 | 边界破坏/安全丧失 | 容器边界被打破 | 安全边界丧失、被侵犯 |
| **BLOCKAGE** | 受阻/障碍/走不通/停滞 | 身体遇到障碍物 | 目标受阻、前进障碍 |
| **FORCE** | 被推动/被拉扯/被压迫/被驱动 | 身体受力 | 被压迫/被驱动、无力感 |
| **SOURCE-PATH-GOAL** | 方向/目标/进展/移动 | 身体从A点到B点 | 目标导向、方向感/目的感 |
| **VERTICALITY** | 高低/升降/层级/地位 | 身体垂直定向（站立/蹲下） | 地位/权力（上高下低）、情绪（上扬下沉） |
| **BALANCE** | 稳定/失衡/调节/倾斜 | 身体维持平衡 | 稳定/失衡、各领域投入比例 |
| **LINK** | 连接/分离/纽带/依附 | 身体与其他物体/人的物理连接 | 关系联结、依恋 |
| **CENTER-PERIPHERY** | 核心/边缘/归属位置/中心性 | 身体在空间中的中心/边缘位置 | 归属感、边缘化、中心性 |

### 规则 2：低频组合走生成规则

当组合不在查表中时：

1. **拆解**：将组合拆为单个图式
2. **映射**：查体验域映射表，得每个图式的体验域
3. **语义合成**：找到各体验域的共同主题——"什么样的体验会同时涉及这些域"
4. **叠加情绪**：用驱动情绪确定翻译的情感方向
5. **填充语境**：用 Step 1 的信息元素（实体/动作/空间）填充具体内容

**约束**：低频组合的翻译输出**必须附合成路径**（哪两个域 → 怎么合 → 得出什么），不能只给结果。这是可审计性的要求——高频组合走查表已有预定义路径，低频组合需要分析者显式写出推理过程。

**语义合成示例**：
- CONTAINER(束缚) + FORCE(被推) → "被推着困在某处" → 被迫停留
- LINK(连接) + BLOCKAGE(受阻) → "想连接但连不上" → 沟通/关系受阻
- VERTICALITY(下降) + CENTER-PERIPHERY(边缘) → "地位下降且被边缘化" → 失去位置

## 四-b、VAD情感维度框架

> VAD（Mehrabian & Russell, 1974）将情绪置于三维正交坐标系。Dream-IEA 以 VAD 作为情绪匹配的理论坐标系——6 类情感是 VAD 空间中的命名簇，intensity 是 A 维度的连续值。

### 三维定义与来源

| 维度 | 含义 | 来源 | 现有系统对应 |
|------|------|------|------------|
| **V 效价** | negative ↔ positive | 仅从情绪来（图式是效价中性的） | 6类情绪已隐含（恐惧/悲伤/愤怒/厌恶=低，喜悦=高，敬畏=中高） |
| **A 唤醒度** | calm ↔ excited | 仅从情绪来（图式无唤醒度） | intensity 0-1 = A 维度的连续值 |
| **D 支配度** | dominant ↔ submissive | **从情绪和图式两边来** | **两边都隐含但未显式标注** |

**关键**：V 和 A 是情绪独有属性，现有系统已完整覆盖。D 是唯一同时从情绪和图式两个来源提供的维度——emotion-D 和 schema-D 的一致/背离是翻译精度的增量来源。

### 6类情绪 → VAD 映射表

| 情绪 | V | A（×intensity） | D（emotion-D） |
|------|---|----------------|---------------|
| 恐惧 | 0.083 | 0.482×i | 0.278 |
| 悲伤 | 0.225 | 0.333×i | 0.149 |
| 愤怒 | 0.122 | 0.830×i | 0.604 |
| 厌恶 | 0.051 | 0.773×i | 0.274 |
| 喜悦 | 1.000 | 0.735×i | 0.772 |
| 敬畏 | 0.650 | 0.710×i | 0.470 |

> V/A/D 值来源：NRC VAD Lexicon v1.0（Mohammad, 2018），Best-Worst Scaling 众包标注，0-1 区间，~20,000 英文词。恐惧对应 "fearful"，喜悦对应 "happy"，悲伤对应 "sad"，愤怒对应 "angry"，厌恶对应 "disgusted"，敬畏对应 "awe"（非基本情绪词，取近似众包值）。A 维度乘以 intensity 得实际唤醒度。非标准情绪（焦虑/平静/愧疚等）先按 `element_typology.md` §四-b 映射到六类，再查此表。

### 图式 → D 贡献表（schema-D）

| 图式 | D 贡献 | 条件 |
|------|--------|------|
| CONTAINER / CONTAINER破裂 / BLOCKAGE | D- | 固定（被困/受阻=被支配） |
| FORCE | D-（被推）/ D+（推人） | 方向依赖 |
| SOURCE-PATH-GOAL | D-（受阻）/ D+（到达） | 结果依赖 |
| VERTICALITY | D-（下降）/ D+（上升） | 方向依赖 |
| CENTER-PERIPHERY | D-（边缘）/ D+（中心） | 位置依赖 |
| BALANCE / LINK | D中性 | 不贡献 D |

> 详见 `element_typology.md` §二 图式表 D贡献列。

## 五、VAD匹配（原"情绪匹配"升级）

翻译链 Step ③ 从"只看情绪标签"升级为"计算完整 VAD 坐标 + D一致性检查"。

### 5.1 情绪 → 翻译方向（保留原映射）

驱动情绪（来自 Step 1 情感元素，Step 2a 统计分布）决定翻译的情感方向：

| 驱动情绪 | V | D | 翻译方向 | 意味着什么在选择 |
|---------|---|---|---------|----------------|
| 恐惧 | - | - | 威胁性体验 | 清醒中存在让梦者害怕的情境，恐惧系统在投票 |
| 悲伤 | - | - | 丧失性体验 | 经历了失去，哀伤系统在投票 |
| 愤怒 | - | + | 边界被侵犯 | 感到被不公正对待，愤怒系统在投票 |
| 厌恶 | - | + | 排斥反应 | 存在想远离的东西，厌恶系统在投票 |
| 喜悦 | + | + | 积极联结 | 有满足/安全的体验，奖赏系统在投票 |
| 敬畏 | + | - | 面对超越框架的事物 | 遇到超出理解的宏大，敬畏系统在投票 |

### 5.2 同一图式组合 + 不同情绪 = 不同翻译

| 图式组合 | 驱动情绪 | emotion-D | schema-D | 翻译 |
|---------|---------|----------|---------|------|
| {CONTAINER + BLOCKAGE} | 恐惧 | D- | D- | 被困且害怕 → 威胁性困境 |
| {CONTAINER + BLOCKAGE} | 悲伤 | D- | D- | 被困且哀伤 → 丧失性困境 |
| {CONTAINER + BLOCKAGE} | 愤怒 | **D+** | **D-** | 被困但愤怒 → 被迫困住的不公正感 **[D张力]** |

### 5.3 D一致性检查

对每个闭合模式，比较 emotion-D 与 schema-D：

| 情况 | 条件 | 处理 |
|------|------|------|
| **D一致** | emotion-D 与 schema-D 方向相同 | 正常翻译，VAD坐标确认翻译方向，不额外标注 |
| **D背离** | emotion-D 与 schema-D 方向相反 | 触发 D 张力调制（见 5.4） |
| **D中性** | schema-D 为中性（BALANCE/LINK） | 仅用 emotion-D，不做一致性检查 |

### 5.4 D张力调制规则

当 emotion-D 与 schema-D 背离时，翻译追加 D 张力标注：

| 场景 | schema-D | emotion-D | 调制方向 |
|------|---------|----------|---------|
| 被困但愤怒 | D-（CONTAINER/BLOCKAGE） | D+（愤怒） | "被困但主动反抗" — 不接受现状 |
| 高处但恐惧 | D+（VERTICALITY上升） | D-（恐惧） | "拥有位置但害怕失去" — 掌控焦虑 |
| 被推但喜悦 | D-（FORCE被推） | D+（喜悦） | "被推动但享受方向" — 顺其自然 |
| 中心但悲伤 | D+（C-P中心） | D-（悲伤） | "处于核心但感到丧失" — 孤独的高处 |

**D 张力调制输出格式**：

```
D张力：schema-D=[低/高]（[图式来源]） vs emotion-D=[低/高]（[情绪来源]）
→ 翻译调制：[调制后的翻译方向]
→ 追问调整：[针对D张力的追问]
```

**D 张力本身是分析信号**——梦者在体验域中的力量位置和情绪立场不一致，这种不一致可能指向：
- 对困境的抵抗（被困+愤怒=不愿接受现状）
- 对权力的恐惧（高处+恐惧=害怕失去掌控）
- 被动接受正面变化（被推+喜悦=顺其自然）

> D 张力不直接降低 C2（输出收敛度），但作为 C2 的辅助调制信号——D 背离且翻译成功调制 → C2 不降；D 背离但无法解释 → C2 降。详见 `scoring.md`。

### 5.5 混合情绪处理

多种情绪同时出现时，取占比最高的为主导情绪，次高的为修饰。VAD 坐标按占比加权：

```
emotion-VAD = Σ(情绪i的VAD × 占比i)

示例：恐惧 60%(V=0.083,D=0.278) + 愤怒 40%(V=0.122,D=0.604)
→ V = 0.083×0.6 + 0.122×0.4 = 0.099
→ D = 0.278×0.6 + 0.604×0.4 = 0.409（低D但被愤怒拉向中位）
→ 翻译："威胁性体验，伴随反抗倾向"
```

## 七、收敛检查（替代六理论交叉校验）

### 原理

同一形成机制产生多个可观测输出。收敛 = 这些输出是否指向同一组体验域 + 同一情绪系统。

不再是"六个理论各跑一遍看是否收敛"——而是检查同一机制的多个输出是否自洽。

### 四个可观测输出 + D张力辅助信号

| 输出 | 反映什么 | 来源 |
|------|---------|------|
| 图式频率/共现 | 哪些体验域被反复激活 | Step 2a 脚本统计 |
| 情感分布 | 哪个情绪系统在驱动选择 | Step 2a 脚本统计 |
| 日间残留 | 哪些近期记忆在处理队列 | Step 2a 标记 |
| 时间趋势 | 情绪强度是否在衰减 | Step 2a 序列观察 |
| **D张力（辅助）** | emotion-D 与 schema-D 是否一致 | Step 2b VAD匹配 |

> D张力不改变4信号收敛判定的主体逻辑，作为辅助调制：
> - D一致 → 收敛判定不变
> - D背离且翻译成功调制 → 收敛判定不变（D张力被解释）
> - D背离但无法解释 → 收敛判定降一级（存在未解释的内部矛盾）

### 收敛判定

| 收敛程度 | 条件 | C2 赋值 |
|---------|------|--------|
| 高收敛 | 4/4 输出指向同一体验域+情绪 | 8-10 |
| 中收敛 | 3/4 一致（1项缺失或弱偏离） | 5-7 |
| 低收敛 | 2/4 一致 | 3-4 |
| 冲突 | 输出指向不同方向 | 1-2 |

### 收敛检查示例

**负面样本**：
- 图式：CONTAINER+BLOCKAGE ×5闭合 → 体验域"被困且受阻" ✓
- 情感：恐惧 86% → 恐惧系统驱动 ✓（与"被困"一致）
- 残留：D7 工作冲突 → 与"被困"关联 ✓
- 趋势：恐惧不衰减 → 卡住（与高频一致） ✓
- D张力：emotion-D=0.278（恐惧）vs schema-D=低（CONTAINER+BLOCKAGE）→ **一致** ✓
- → 4/4 收敛 + D一致 → C2 = 8

**正面样本**：
- 图式：VERTICALITY/LINK/CONTAINER/FORCE 多样 → 体验域分散但同正价
- 情感：喜悦 81.4% + 敬畏 18.6% → 积极系统驱动 ✓
- 残留：D7 收到 offer → 与正面体验关联 ✓
- 趋势：积极情绪减弱中（slope=-0.025）→ 正向体验可能减少 ⚠
- D张力：emotion-D=0.772（喜悦）vs schema-D 混合（VERTICALITY上升=高D, LINK=D中性）→ **一致** ✓
- → 3/4 收敛（图式分散但情绪/残留/趋势方向一致，趋势为减弱需关注）+ D一致 → C2 = 6

---

## 八、特殊情形

### 日间残留主导

如果大部分梦都是日间残留（当天事件的直接回放），图式可能无法形成闭合模式。

翻译：正常记忆整合，不构成深层心理信号。C2 低但 C1 可能仍达标。

### 创伤模式（衰减失败）

图式模式闭合 + 情绪强度不随时间递减 = 处理卡住。

判断标准：
- 同一图式组合闭合（≥3 次）
- 驱动情绪占比持续 >50% 且无下降趋势
- → 翻译中标注"衰减失败"，触发风险标记规则

### 正面模式

同一机制适用。喜悦驱动的 LINK/BALANCE/SPG 高频 = 积极体验域回路在清醒中活跃。同等翻译逻辑，同等权重。（R7 的机制基础）

### 混合情绪

多种情绪同时高占比时，梦者可能处于复杂情绪状态。取主导情绪为翻译驱动，次要情绪作为修饰词附加。

## 九、理论支撑（原六理论的重新定位）

六理论不再作为独立翻译路径，而是作为形成机制不同侧面的理论佐证：

| 理论 | 在形成机制中的位置 |
|------|------------------|
| 具身认知 | 解释**为什么图式是大脑的原生建筑模块**——抽象思维建立在身体经验隐喻上 |
| 连续性假设 | 解释**为什么清醒回路会在睡眠中回放**——梦境内容与清醒关注连续 |
| 威胁模拟 | 解释**为什么威胁相关内容被优先选择**——威胁回路具有高生存突显性 |
| 记忆再激活 | 解释**为什么日间残留出现**——海马体重新激活白天编码的记忆 |
| 情绪调节 | 解释**为什么情绪强度可能衰减**——REM 睡眠在安全环境重新处理情绪记忆 |
| 自我组织 | 解释**为什么新奇组合出现**——低约束状态下的认知-情感探索 |

每条理论照亮同一机制的一个侧面，不再是并行翻译镜头。

### 排除的理论

| 理论 | 原因 |
|------|------|
| 弗洛伊德象征 / 梦典 | 跳过意象图式层直接做「梦到 X = Y」，不可证伪 |
| 纯随机激活论 | 否定梦编码了信息——整个翻译层前提不成立 |
| 荣格原型 | 倾向象征而非具身图式落地，即使引用也须通过图式层 |

## 十、全谱原则

六类情感元素（恐惧/敬畏/厌恶/喜悦/悲伤/愤怒）均须被翻译覆盖。若分析只产出负面假设，检查是否遗漏了日记中的正面/其他情绪片段——这是标注偏差，不是梦只有负面。
