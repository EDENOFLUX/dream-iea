# 元素类型学与意象图式速查

> 本文件是 Dream-IEA Step 1-2a 的参考规范：七类信息元素定义 + 意象图式映射 + 标注示例 + 稳定性层级 + Gestalt 闭合检测。

---

## 一、七类信息元素

| # | 类别 | 身体锚点 | 子类/例 |
|---|------|---------|--------|
| 1 | 实体元素 | 物体恒常性 + 基本层次范畴 | 自然物（水/火/山）、生物（蛇/鸟）、人造物（船/建筑） |
| 2 | 动作元素 | 运动知觉 + 动觉 | 位移（升起/沉没）、转化（死亡/诞生）、传递（赐予/吞食）、作用力（击打/淹没） |
| 3 | **空间-关系元素** | **意象图式系统** | **见下表 ← Step 2a 入口** |
| 4 | 性质元素 | 原始感官模态 | 视觉（亮/暗）、触觉（热/冷）、听觉（咆哮）、动觉（轻/重）、嗅觉味觉（腥/甜） |
| 5 | 情感元素 | 自主神经系统激活 | 恐惧/敬畏/厌恶/喜悦/悲伤/愤怒 |
| 6 | 抽象结构元素 | 身体经验组合/映射 | 因果/意图/否定/数量序列/同一性 |
| 7 | 元元素 | 叙事本身的元信息 | 保密标记/层次标记/解码指令/传播禁制 |

## 二、意象图式 ↔ 体验域 ↔ 身体起源 ↔ 梦中典型表现 ↔ 清醒心理操作

> 体验域是 Step 2b 翻译的查表基础。图式 → 体验域 → 体验域合成 → VAD匹配 → 清醒体验。详见 `theory_translation.md`。
> D贡献列：图式对 VAD 支配度维度的贡献。D- = 被支配方向，D+ = 主动支配方向，D中性 = 不贡献。部分图式的 D 方向是上下文依赖的。

| 意象图式 | 体验域 | 身体起源 | 梦中典型表现 | 清醒心理操作 | D贡献 |
|---------|--------|---------|------------|------------|------|
| **CONTAINER** | 进出/包容/排斥/束缚/自由 | 身体作为容器、进出经验 | 被困、囚禁、无法出去、被包围 | 归属/排斥、束缚/自由感 | D- |
| 容器破裂 | 边界破坏/安全丧失 | 容器边界被破坏 | 房屋漏水、墙壁倒塌、门无法关闭 | 安全边界丧失、被侵犯 | D- |
| **SOURCE-PATH-GOAL** | 方向/目标/进展/移动 | 行走的轨迹 | 迷路、找不到目的地、追赶/被追赶 | 目标导向、方向感/目的感 | D-（受阻）/ D+（到达） |
| **VERTICALITY** | 高低/升降/层级/地位 | 站立、躺下、上升 | 坠落、飞翔、爬升、下沉 | 地位/权力、情绪（上扬下沉） | D-（下降）/ D+（上升） |
| **BALANCE** | 稳定/失衡/调节/倾斜 | 保持直立 | 站立不稳、摔倒、无法保持平衡 | 稳定/失衡、各领域投入比例 | D中性 |
| **LINK** | 连接/分离/纽带/依附 | 身体接触、脐带 | 断线、无法连接、失去联系 | 关系联结、依恋 | D中性 |
| **CENTER-PERIPHERY** | 核心/边缘/归属位置/中心性 | 身体核心 vs 四肢 | 被排除、在边缘、无法进入中心 | 归属感、边缘化、中心性 | D-（边缘）/ D+（中心） |
| **FORCE** | 被推动/被拉扯/被压迫/被驱动 | 推、拉、阻挡、支撑 | 被压迫、无法推动、被强力移动 | 被压迫/被驱动、无力感 | D-（被推）/ D+（推人） |
| **BLOCKAGE** | 受阻/障碍/走不通/停滞 | 路被挡住 | 路被挡住、门打不开、无法通过 | 目标受阻、前进障碍 | D- |

## 三、标注示例

```
梦境："我在一个很暗的地下停车场，找不到出口。有一个模糊的人影一直跟着我，
但我不确定他是谁。我很害怕，想跑但腿很重跑不动。后来墙突然裂开了，水涌进来，我醒了。"

- 实体元素：地下停车场(人造物)、人影(生物/模糊)、水(自然物)
- 动作元素：找(位移·目标)、跟着(位移·追踪)、跑(位移·逃避)、涌进来(位移·进入)
- 空间-关系元素 ← Step 2a 入口：
  - CONTAINER: 地下=下面、停车场=封闭容器、找不到出口=容器无开口
  - BLOCKAGE: 腿很重=自身运动受阻
  - CONTAINER破裂: 墙裂开=容器边界破坏
  - FORCE: 水涌进来=外部力侵入容器
- 性质元素：暗(视觉)、重(动觉)
- 情感元素：害怕(恐惧)
- 抽象结构元素：不确定=否定+同一性(无法识别跟踪者)
```

## 四、稳定性层级

- 空间-关系元素**最稳定**（全人类共享身体结构 → 共享意象图式）
- 实体元素次之（受环境/个人经验影响）
- 情感元素最易被文化/个人过滤层改写

## 四-b、非标准情绪映射约定

六类情感元素（恐惧/敬畏/厌恶/喜悦/悲伤/愤怒）是分析的基础类型。但梦者常用更细粒度的情绪词描述感受。标注时须映射到六类之一：

| 常见梦情绪 | 映射到 | 理由 |
|----------|--------|------|
| 焦虑、紧张、恐慌、害怕 | 恐惧 | 均为威胁检测系统激活的不同强度/时相 |
| 满足、兴奋、快乐、释然、开心、幸福 | 喜悦 | 均为奖赏系统正向激活 |
| 愧疚、无力、失落、孤独、沮丧 | 悲伤 | 均为丧失/低落系统激活 |
| 尴尬、恶心、反感 | 厌恶 | 均为排斥反应系统激活 |
| 生气、烦躁、恼怒 | 愤怒 | 均为边界侵犯-对抗系统激活 |
| 惊奇、震撼、崇敬 | 敬畏 | 均为面对超越框架事物的反应 |
| 平静 | （不映射） | 平静是低激活状态，非六类之一；若为次要情绪可省略，若为主导需注明"低激活中性" |

> **映射原则**：映射的是底层情绪系统，不是语义精确匹配。焦虑和恐惧在体验上不同，但共享威胁检测回路——从形成机制角度，它们是同一个"投票系统"的不同表现。
>
> **脚本校验**：`analyze_dreams.py` 会对非六类情绪类型发出警告并给出映射建议（见 `EMOTION_MAPPING_HINTS`），但不自动转换——分析者须确认映射后修改 JSON。

## 五、Gestalt 闭合检测

同一图式组合跨日记重复：
- 不闭合（单次）：不足以判断
- 部分闭合（≥3 篇）：开始有诊断价值
- 完全闭合（≥5 篇）：心理锚点

**实现方式**：
1. 优先使用 JSON 中的 `schema_combo` 字段（分析者标注的组合模式）
2. 若无 `schema_combo`，回退到共现统计（同篇内两两组合频率）
3. 取最大重复次数映射 S1 闭合度评分

## 六、日间残留检测

- `day_residue: true` → 标记为当天事件的直接回放（如看了电影后梦到电影场景）
- `day_residue: false` → 深层图式模式候选
- 残留篇不参与 Gestalt 闭合的核心模式判断，但仍在频率统计中保留
