# 评分与置信度规范（对齐 LPP）

> 本文件是 Dream-IEA Step 2a-2b 的评分规范：■●▲△ 置信标记、1-10 光谱打分、综合指数公式、R1-R7 硬规则。

---

## 一、置信度标记 ■ ● ▲ △

| 标记 | 级别 | 触发条件 | 措辞纪律 |
|------|------|---------|---------|
| ■ 强信号 | 高置信 | 完全闭合 + 高收敛(4/4输出一致) + 跨日记稳定 | 用「反映 / 显示 / 表明」 |
| ● 中信号 | 中置信 | 部分闭合 + 中收敛(3/4) / 或低收敛但闭合充分 | 用「可能 / 倾向于 / 指向」 |
| ▲ 弱信号 | 低置信 | 单次或低收敛，无交叉验证 | 用「有限证据提示 / 不排除」 |
| △ 探索 | 探索性 | 模式有趣但证据不足，不评分 | 仅标注，附局限提示 |

**措辞纪律（硬约束）**：■ 不得用「可能」，▲ 不得用「反映」。错配是报告审计的一票否决。

## 二、光谱打分维度（1-10）

### 脚本自动计算

| 代号 | 维度 | 1-10 锚点 | 计算方式 |
|------|------|----------|---------|
| C1 | 数据充分度 | N=1→1 ｜ N=7→5 ｜ N=14+→10 | 线性插值 |
| S1 | 图式闭合度 | 单次1 ｜ 弱闭合(×2)3 ｜ 部分闭合(≥3)5 ｜ 完全闭合(≥5)9 | 最大组合重复次数 |
| S2 | 基线偏离度 | 持平1 ｜ 1.5×基线5 ｜ ≥2×基线10 | 各图式偏离个人基线的最大倍数 |
| S3 | 情感主导度 | 均布1 ｜ 单一占0.4为5 ｜ 占0.8+为10 | 最大单一情感占比（不入综合公式） |

### 分析者按规则赋值（须注明来源）

| 代号 | 维度 | 赋值规则 |
|------|------|---------|
| C2 | 输出收敛度 | 冲突1-2 ｜ 低收敛(2/4)3-4 ｜ 中收敛(3/4)5-7 ｜ 高收敛(4/4)8-10 |
| C3 | 时间趋势 | 无趋势3 ｜ 弱5 ｜ 单调下降/上升清晰10（仅情绪相关推断） |
| C4 | 传记共振 | 无同构0-2 ｜ 弱4-5 ｜ 明确同构8 ｜ 强共振9-10 |

#### C2 辅助信号：D张力调制

C2 的主体逻辑基于4信号收敛判定（图式/情绪/残留/趋势）。VAD的D张力作为辅助调制信号：

| D张力状态 | 对C2的影响 | 说明 |
|----------|-----------|------|
| D一致（emotion-D = schema-D） | 不影响 | 情绪支配度与图式支配度方向一致，确认翻译方向 |
| D背离 + 翻译成功调制 | 不影响 | D张力被解释并纳入翻译（如"被困但反抗"），内部矛盾已解决 |
| D背离 + 无法解释 | C2 降一级 | 存在未解释的内部矛盾，翻译可靠性下降 |
| D中性（schema为BALANCE/LINK） | 不影响 | 图式不贡献D，仅用emotion-D，不做一致性检查 |

> D张力来源：Step 2b VAD匹配（详见 `theory_translation.md` §五）。大多数梦境D一致（图式和情绪自然匹配），D背离是有价值的分析信号而非错误。

#### C4 同构判定标准

| 等级 | 分值 | 判定条件 |
|------|------|---------|
| 无同构 | 0-2 | 梦者未提供足够传记信息，或图式模式与已知传记无对应 |
| 弱同构 | 4-5 | 图式模式与生命情境在主题上有间接关联，但非直接对应 |
| 明确同构 | 8 | 图式闭合模式与梦者自述的当前生命情境在体验域层面直接对应（如梦反复 CONTAINER+BLOCKAGE，梦者自述工作中被困住） |
| 强共振 | 9-10 | 明确同构 + 跨多年反复出现同一模式 |

## 三、综合置信度指数（启发式）

```
综合指数 = 0.25·C1 + 0.25·S1 + 0.20·C2 + 0.15·S2 + 0.15·C4
         （C3 仅当推断涉及情绪时纳入，或按 R5 记 5）
```

**映射标记**：综合 ≥7.0 → ■ ｜ 4.0–6.9 → ● ｜ <4.0 → ▲

## 四、IF-THEN 硬规则（优先级高于公式）

> **执行边界**：R1-R4 由脚本 `analyze_dreams.py` 在 `apply_rules()` 中自动强制执行；R5-R7 是分析者手动规则，脚本不自动处理，分析者须在报告中显式说明是否触发。

| 规则 | 条件 | 动作 | 执行者 |
|------|------|------|--------|
| R1 闭合门槛 | S1 == 不闭合（单次） | 该推断封顶 ▲ | 脚本自动 |
| R2 数据门槛 | C1 < 5（N < 7） | 综合封顶 ●（不出 ■） | 脚本自动 |
| R3 高置信触发 | S1 == 完全闭合 且 C2 ≥ 7（高收敛）且 S2 ≥ 5（基线偏离达标） | 综合 ≥ ■ | 脚本自动 |
| R4 低收敛封顶 | C2 < 3.4（低收敛/冲突） | 综合封顶 ● | 脚本自动 |
| R5 情绪趋势中性 | 推断涉及情绪但 C3 未知 | C3 按 5 计 | 分析者手动 |
| R6 风险降权 | 触发风险标记且梦者否认/无现实锚点 | 该推断降一档，标注「需现实核查」 | 分析者手动 |
| R7 正面模式同权 | 正面情绪模式（喜悦/敬畏/连接） | 与负面模式同等打分，不降权 | 分析者手动 |

## 七、基线来源与校准

### 默认基线

脚本内置的 `DEFAULT_BASELINE`（CONTAINER: 0.3, BLOCKAGE: 0.2, FORCE: 0.1 等）是基于意象图式在一般人群中的**经验估计值**，非严格统计数据。用于新梦者尚无历史数据时的参照系。

**局限**：默认基线不考虑个体差异。同一个 CONTAINER 频率，对一个长期焦虑的人和对一个平静期的人含义不同。

### 个人校准基线

当 JSON 顶层提供 `baseline` 字段时，脚本使用个人校准基线（覆盖默认值）。报告输出中标注当前使用的基线类型。

**校准建议**：积累 ≥14 篇标注日记后，从前 7-14 篇计算各图式的个人频率分布，作为后续分析的校准基线。校准基线使 S2（基线偏离度）的判定更有个体针对性。

### 基线类型标注

脚本输出报告中「图式频率」段首行标注基线来源：
- `个人校准基线（JSON 提供）`：JSON 包含 baseline 字段
- `默认基线（未经个人校准，建议积累≥14篇后校准）`：使用内置默认值
