## 一、总纲：三层映射（不可跳步）

```
梦境叙事（碎片化 or 完整均可）
  ↓ Step 1: 元素解码       → 信息元素（客观标注，不解释）
  ↓ Step 2a: 图式识别      → 意象图式（客观模式检测，不推断）
  ↓ Step 2b: 理论翻译      → 心理状态（心理学/神经科学驱动）
  ↓ Step 3: 三线叠图       → 锚定到个人时空框架
```

**铁律**：信息元素不直接指向心理状态。必须经过意象图式中层。绝不做「梦到 X = 你在 Y」的象征跳译。

**输入兼容**：碎片化（词组/短句/跳跃片段）和完整叙事（语法规范）同等对待，走同一解码路径。

## 二、七类信息元素 + 意象图式速查

### 2.1 七类元素

| # | 类别 | 身体锚点 | 子类/例 |
|---|------|---------|--------|
| 1 | 实体元素 | 物体恒常性 + 基本层次范畴 | 自然物（水/火/山）、生物（蛇/鸟）、人造物（船/建筑） |
| 2 | 动作元素 | 运动知觉 + 动觉 | 位移（升起/沉没）、转化（死亡/诞生）、传递（赐予/吞食）、作用力（击打/淹没） |
| 3 | **空间-关系元素** | **意象图式系统** | **见下表 ← Step 2a 入口** |
| 4 | 性质元素 | 原始感官模态 | 视觉（亮/暗）、触觉（热/冷）、听觉（咆哮）、动觉（轻/重）、嗅觉味觉（腥/甜） |
| 5 | 情感元素 | 自主神经系统激活 | 恐惧/敬畏/厌恶/喜悦/悲伤/愤怒 |
| 6 | 抽象结构元素 | 身体经验组合/映射 | 因果/意图/否定/数量序列/同一性 |
| 7 | 元元素 | 叙事本身的元信息 | 保密标记/层次标记/解码指令/传播禁制 |

### 2.2 意象图式 ↔ 身体起源 ↔ 梦中典型表现

| 意象图式 | 身体起源 | 梦中典型表现 |
|---------|---------|------------|
| **CONTAINER** | 身体作为容器、进出经验 | 被困、囚禁、无法出去、被包围 |
| 容器破裂 | 容器边界被破坏 | 房屋漏水、墙壁倒塌、门无法关闭 |
| **SOURCE-PATH-GOAL** | 行走的轨迹 | 迷路、找不到目的地、追赶/被追赶 |
| **VERTICALITY** | 站立、躺下、上升 | 坠落、飞翔、爬升、下沉 |
| **BALANCE** | 保持直立 | 站立不稳、摔倒、无法保持平衡 |
| **LINK** | 身体接触、脐带 | 断线、无法连接、失去联系 |
| **CENTER-PERIPHERY** | 身体核心 vs 四肢 | 被排除、在边缘、无法进入中心 |
| **FORCE** | 推、拉、阻挡、支撑 | 被压迫、无法推动、被强力移动 |
| **BLOCKAGE** | 路被挡住 | 路被挡住、门打不开、无法通过 |

### 2.3 标注示例

```
梦境："我在一个很暗的地下停车场，找不到出口。有一个模糊的人影一直跟着我，
但我不确定他是谁。我很害怕，想跑但腿很重跑不动。后来墙突然裂开了，水涌进来，我醒了。"

- 实体元素：地下停车场(人造物)、人影(生物/模糊)、水(自然物)
- 动作元素：找(位移·目标)、跟着(位移·追踪)、跑(位移·逃避)、涌进来(位移·进入)
- 空间-关系元素 ← Step 2a 入口：
  - CONTAINER: 地下=下面、停车场=封闭容器、找不到出口=容器无开口
  - BLOCKAGE: 腿很重=自身运动受阻
  - CONTAINER破裂: 墙裂开=容器边界破坏
  - FORCE: 水涌进来=外部力侵入容器
- 性质元素：暗(视觉)、重(动觉)
- 情感元素：害怕(恐惧)
- 抽象结构元素：不确定=否定+同一性(无法识别跟踪者)
```

### 2.4 稳定性层级

- 空间-关系元素**最稳定**（全人类共享身体结构 → 共享意象图式）
- 实体元素次之（受环境/个人经验影响）
- 情感元素最易被文化/个人过滤层改写

### 2.5 Gestalt 闭合检测

同一图式组合跨日记重复：
- 不闭合（单次）：不足以判断
- 部分闭合（≥3 篇）：开始有诊断价值
- 完全闭合（≥5 篇）：心理锚点

## 三、六理论翻译函数

### 3.1 入选逻辑

三个必要条件（缺一不可）：
- (a) 把意象图式当作真实认知基元（不是纯语言修辞）
- (b) 通过图式连接梦内容到清醒心理状态
- (c) 可被实证检验（翻译可证伪，不是玄学）

### 3.2 六理论

| 理论 | 核心主张 | 翻译方向 | 输入维度 |
|------|---------|---------|---------|
| **具身认知**（Lakoff & Johnson） | 抽象思维建立在身体经验的隐喻映射 | 每个图式 = 一个身体隐喻域，图式激活 = 该域心理操作在运行 | 图式本身 |
| **连续性假设**（Domhoff） | 梦境内容与清醒关注/情绪/社交连续 | 图式激活频率 → 清醒生活中对应身体隐喻的经验频率 | 图式频率 |
| **威胁模拟**（Revonsuo） | 梦的功能是模拟威胁以增强适应性 | 威胁相关图式 + 恐惧 → 威胁检测系统在安全环境模拟运行 | 图式组合内容 |
| **记忆再激活与整合** | 睡眠中海马体重新激活白天编码的记忆 | 日间残留中的图式 → 相关记忆正整合进长时记忆网络 | 残留标记 |
| **情绪调节理论** | REM 睡眠在安全环境重新处理情绪记忆 | 恐惧+图式组合频率随时间递减 → 情绪处理进展中；不递减 → 受阻 | 时间趋势 |
| **自我组织理论**（Kahn & Hobson） | 梦是感觉输入减少时大脑自我组织活动 | 非常见图式共现 → 低约束状态下的认知-情感整合探索 | 组合新奇度 |

### 3.3 排除的理论

| 理论 | 原因 |
|------|------|
| 弗洛伊德象征 / 梦典 | 跳过意象图式层直接做「梦到 X = Y」，不可证伪 |
| 纯随机激活论 | 否定梦编码了信息——整个翻译层前提不成立 |
| 荣格原型 | 倾向象征而非具身图式落地，即使引用也须通过图式层 |

### 3.4 翻译操作步骤

```
1. 拆解图式模式 P：频率 / 组合 / 情感 / 时间趋势 / 残留标记
2. 对每个适用于 P 的理论，套用它的映射规则，产出假设 H_T
   （所有相关理论各跑一遍，它们看的是图式模式的不同维度）
3. 收集 {H_T}
4. 交叉校验：多个理论收敛到同一心理状态 → 高置信；冲突/单支持 → 低置信
5. 用 Step 3 近期事件线 / 传记线把方向性假设锚定到具体生活领域
```

### 3.5 常见图式模式翻译（全情绪谱）

**负面/威胁类：**

| 图式模式 | 翻译 |
|---------|------|
| {CONTAINER + BLOCKAGE} 高频 | 连续性：清醒生活中「被困+受阻」身体隐喻反复激活 |
| {FORCE + CONTAINER破裂 + 恐惧} 闭合 | 威胁模拟 + 连续性 + 情绪调节 → 边界被外力突破的威胁，交叉一致性**高** |
| {VERTICALITY坠落 + LINK断裂} | 具身：向下运动+连接断开的复合隐喻 |
| {SOURCE-PATH-GOAL 迷路} 高频 | 连续性：生活中缺乏清晰路径/方向感 |
| {BALANCE 失衡} 高频 | 具身：对称/均衡维持失效，某领域过度投入 |
| {CENTER-PERIPHERY 被排除} | 连续性：归属感问题，社交/工作中被边缘化 |
| {CONTAINER破裂 + 悲伤} 闭合 | 具身 + 连续性：安全容器破损+悲伤，近期可能经历分离/丧失 |

**正面/积极类（R7 同权，不因「积极」降权）：**

| 图式模式 | 翻译 |
|---------|------|
| {VERTICALITY 飞翔 + 喜悦} 高频 | 具身：向上运动+掌控感隐喻。清醒中拥有自主/胜任体验 |
| {LINK 连接 + 喜悦} 闭合 | 具身：连接/纽带隐喻+正面情感。关系联结被满足 |
| {SOURCE-PATH-GOAL 到达 + 喜悦} 高频 | 具身：路径达成隐喻。目标达成/方向清晰 |
| {CONTAINER 被包裹 + 敬畏} 高频 | 具身：安全容器+敬畏。处于被庇护/崇高的体验中 |
| {BALANCE 平衡 + 喜悦} 闭合 | 具身：均衡维持+正面。生活各领域较均衡 |

**混合/复杂类：**

| 图式模式 | 翻译 |
|---------|------|
| {CONTAINER破裂 + 悲伤 → CONTAINER修复 + 喜悦} 时间序列 | 情绪调节：先丧失后修复轨迹，情绪处理进展中 |
| {VERTICALITY 坠落(恐惧) + VERTICALITY 飞翔(喜悦)} 交替 | 具身：垂直轴双向摆动。清醒中掌控感起伏大 |

### 3.6 全谱原则

六类情感元素（恐惧/敬畏/厌恶/喜悦/悲伤/愤怒）均须被翻译覆盖。若分析只产出负面假设，检查是否遗漏了日记中的正面/其他情绪片段——这是标注偏差，不是梦只有负面。

## 四、光谱评分与置信度（对齐 LPP）

### 4.1 置信度标记 ■ ● ▲ △

| 标记 | 级别 | 触发条件 | 措辞纪律 |
|------|------|---------|---------|
| ■ 强信号 | 高置信 | 完全闭合 + ≥3 理论收敛 + 跨日记稳定 | 用「反映 / 显示 / 表明」 |
| ● 中信号 | 中置信 | 部分闭合 + ≥2 理论 / 或单理论但闭合充分 | 用「可能 / 倾向于 / 指向」 |
| ▲ 弱信号 | 低置信 | 单次或仅单理论，无交叉验证 | 用「有限证据提示 / 不排除」 |
| △ 探索 | 探索性 | 模式有趣但证据不足，不评分 | 仅标注，附局限提示 |

**措辞纪律（硬约束）**：■ 不得用「可能」，▲ 不得用「反映」。错配是报告审计的一票否决。

### 4.2 光谱打分维度（1-10）

**脚本自动计算：**

| 代号 | 维度 | 1-10 锚点 |
|------|------|----------|
| C1 | 数据充分度 | N=1→1 ｜ N=7→5 ｜ N=14+→10 |
| S1 | 图式闭合度 | 单次1 ｜ 部分闭合(≥3天)5 ｜ 完全闭合(≥5天)9 |
| S2 | 基线偏离度 | 持平1 ｜ 1.5×基线5 ｜ ≥2×基线10 |
| S3 | 情感主导度 | 均布1 ｜ 单一占0.4为5 ｜ 占0.8+为10 |

**分析者按规则赋值（须注明来源）：**

| 代号 | 维度 | 赋值规则 |
|------|------|---------|
| C2 | 理论一致性 | 单理论3 ｜ 2理论5 ｜ 3+理论收敛8 ｜ 高一致10 |
| C3 | 时间趋势 | 无趋势3 ｜ 弱5 ｜ 单调下降/上升清晰10（仅情绪相关推断） |
| C4 | 传记共振 | 无同构0 ｜ 弱4 ｜ 明确同构8 ｜ 强共振10 |

### 4.3 综合置信度指数（启发式）

```
综合指数 = 0.25·C1 + 0.25·S1 + 0.20·C2 + 0.15·S2 + 0.15·C4
         （C3 仅当推断涉及情绪时纳入，或按 R5 记 5）
```

**映射标记**：综合 ≥7.0 → ■ ｜ 4.0–6.9 → ● ｜ <4.0 → ▲

### 4.4 IF-THEN 硬规则（优先级高于公式）

| 规则 | 条件 | 动作 |
|------|------|------|
| R1 闭合门槛 | S1 == 不闭合（单次） | 该推断封顶 ▲ |
| R2 数据门槛 | C1 < 5（N < 7） | 综合封顶 ●（不出 ■） |
| R3 高置信触发 | S1 == 完全闭合 且 C2 ≥ 6（≥3理论） | 综合 ≥ ■ |
| R4 单理论封顶 | C2 < 3.4（仅单理论） | 综合封顶 ● |
| R5 情绪趋势中性 | 推断涉及情绪但 C3 未知 | C3 按 5 计 |
| R6 风险降权 | 触发风险标记且梦者否认/无现实锚点 | 该推断降一档，标注「需现实核查」 |
| R7 正面模式同权 | 正面情绪模式（喜悦/敬畏/连接） | 与负面模式同等打分，不降权 |

### 4.5 光谱呈现格式（每条推断必附）

```
推断：当前核心为「被困+边界受压」三重隐喻
─────────────────────────────────────────
维度              光谱(1-10)
数据充分度   ▓▓▓▓▓░░░░░  5   (N=7 → 脚本自动)
图式闭合度   ▓▓▓▓▓▓▓▓▓░  9   (完全闭合×5 → 脚本自动)
理论一致性   ▓▓▓▓▓░░░░░  5   (连续性+具身 2理论 → 分析者赋)
基线偏离度   ▓▓▓▓▓▓▓▓▓▓ 10   (BLOCKAGE 4.3×基线 → 脚本自动)
传记共振     ▓▓▓▓▓░░░░░  4   (无明确同构 → 分析者赋)
─────────────────────────────────────────
综合置信度   ▓▓▓▓▓░░░░░  ● [6.6]  中信号
判定：R2(N=7→C1=5不封顶)；R3未触发(C2=5<6)；R4不触发(C2≥3.4)
```

## 五、操作流程

### Step 0：个人感觉景观校准

建立梦者的「感觉基线」——提问获取：近期 1-2 周生活状态、压力事件、长期情绪基调、创伤史（自愿）、文化背景。

### Step 1：元素解码

逐篇标注七类信息元素，**只做识别不做解释**。碎片化输入直接映射；完整叙事先去叙事化再拆解。

### Step 2a：图式识别（客观层）

运行 Python 脚本或手动统计：
- 图式频率（对比基线）
- 图式共现聚类
- 情感分布（全谱，正负对称检测）
- Gestalt 闭合检测
- 日间残留检测（区分当天回放 vs 深层模式）

### Step 2b：理论翻译（推断层）

对每个闭合图式模式，套用六理论各跑一遍，交叉校验收敛度，用追问句式交还梦者验证。

### Step 3：三线叠图

| 线 | 内容 | 来源 |
|----|------|------|
| 图式分布线 | Step 2a 输出 | 梦境标注 |
| 个人传记线 | 生命史关键节点/创伤/转折 | Step 0 + 用户补充 |
| 近期事件线 | 梦前 1-7 天事件时间线 | 每日配注 |

三线交会 = 心理状态推断锚点。

### 输出三层

- **第一层**（■ 高置信 · 客观）：图式激活数据，不引入理论
- **第二层**（● 中置信 · 需确认）：理论翻译 + 追问句式
- **第三层**（▲ 弱信号 · 需验证）：图式模式与传记交叉，识别跨时间同构

## 六、约束与边界

- **不替代临床诊断**：不产出 DSM/ICD 标签。持续高强度负面图式模式 → 建议寻求专业帮助
- **需要梦者验证**：第二、三层推断必须经用户确认
- **日记数量下限**：至少 7 篇，理想 14 篇
- **置信度必须可追溯**：每个子维度分数 + 来源（脚本自动/分析者赋值）必须明示
- **综合指数为启发式**：权重基于专家判断而非经验校准，不提供统计可靠性保证
- **全情感谱覆盖**：不因「积极」降权（R7），不因「负面」放大

---

## 七、风险标记规则

以下模式出现时，明确建议寻求专业帮助（不自行诊断）：
- 反复 {FORCE + CONTAINER破裂 + 恐惧} 且不闭合（连续多日，强度不降）
- 情感分布中恐惧/悲伤占比持续 >50% 且无下降趋势
- 自我否定/消失类图式（同一性否定 + CENTER-PERIPHERY 极端边缘化）密集出现

措辞：「该图式模式显示高强度且未缓解的情绪负荷，建议考虑与心理健康专业人士交谈。」
