# 双面报告模板

> 每次分析完成后，按此模板输出双面报告。报告分两部分，面向不同阅读需求。

---

## 核心原则

```
第一部分（梦境画像）        第二部分（评分与解释）
 感性 · 可读性优先           理性 · 分析性优先
 先让人"感觉对"              后让人"理解为什么"
 不出现技术标记              每一步都可追溯
```

两部分基于同一套 Step 1→Step 3 的分析结果，不矛盾。审计方法：逐句检查第一部分的每个描述，在第二部分中都能找到对应的图式/情绪/趋势证据。

---

## 报告深度规则

| 日记数量 | 报告范围 | 说明 |
|---------|---------|------|
| 1 篇 | 仅第一部分 | 标注"单篇分析，统计维度不可用，以下为基于单篇的初步翻译" |
| 2-6 篇 | 第一部分 + 第二部分精简 | 第二部分仅图式数据 + 翻译 + 光谱评分，无趋势/基线偏离 |
| ≥7 篇 | 完整双面报告 | 两部分完整输出 + 收敛预检 + 趋势分析 + 基线偏离 |
| ≥14 篇 | 完整 + 个人基线 | 第二部分基线来源标注"个人校准基线" |

---

## 第一部分：梦境画像

### 定位

这是梦者第一眼看到的内容。目标是让梦者读完说"这说的就是我的梦"，而不是"这是一堆图式术语"。

### 写作规则

1. **图式模式驱动**：每一句描述的底牌都是反复出现的图式模式及其翻译，但图式名称/编号不出现在表层叙述中
2. **硬币两面**：每个特征呈现信号 + 含义。"你的梦在反复呈现 X" → "这可能指向 Y"
3. **用"你"贯穿**，直接与梦者对话
4. **不出现任何技术标记**：没有图式编号（CONTAINER/BLOCKAGE）、没有光谱数值（1-10）、没有评分条（▓▓▓░░）、没有 R 规则、没有 C1/C2/S1 代码
5. **第一条定调**：报告的开头第一句最重要——给出核心判断，让梦者立刻感觉到"这说的就是我的梦"
6. **追问句式**：翻译结果必须以追问交还梦者验证，不从分析者口中下结论
7. **自然收束**：不以"总之""综上所述"结尾。以建设性视角收尾，让梦者读完后有方向感

### 叙事结构

以下为第一部分**必须出现的段落**，按顺序排列。每段的实际内容自由发挥，但段落类型和顺序不可跳过或调换。

```
┌─ 段落1：定调句 ──────────────────────────────┐
│ 1-2句，给出核心梦境主题判断                        │
│ 句式示例：「你的梦在一遍遍回到同一个主题——」       │
│ 要求：读完这句梦者想说"这说的就是我的梦"            │
│ <7篇时调整为单篇定调：「这个梦的核心是——」         │
└────────────────────────────────────────────────┘
        ↓
┌─ 段落2：主导梦境模式 ──────────────────────────┐
│ 2-4句，叙事性翻译                                  │
│ 梦境反复出现什么场景/感受 → 这在指向什么清醒体验     │
│ 硬币两面：信号 → 可能含义                           │
│ 用日常语言描述体验域合成结果，不说"体验域"这个词     │
└────────────────────────────────────────────────┘
        ↓
┌─ 段落3：情绪基调 ─────────────────────────────┐
│ 1-3句，梦境的情绪色彩                              │
│ 什么情绪在驱动这些梦 → 它的强度和分布               │
│ 用日常语言：恐惧/喜悦/悲伤/愤怒/敬畏/厌恶           │
│ 不说"恐惧占比0.971"，说"恐惧几乎是唯一的底色"       │
└────────────────────────────────────────────────┘
        ↓
┌─ 段落4：时间动态（≥7篇时出现） ────────────────┐
│ 1-2句，趋势叙事                                    │
│ 用日常语言：在减弱/在持续/卡住了/在增强              │
│ 不说"slope=-0.01"，说"这种恐惧从第一天到最后一天     │
│ 几乎没有减弱"                                      │
│ <7篇时此段跳过                                     │
└────────────────────────────────────────────────┘
        ↓
┌─ 段落5：追问句式 ─────────────────────────────┐
│ 以「你最近是否…？」开头                            │
│ 1-3条追问，每条一句话                              │
│ 追问从翻译推导而来，不凭空编造                      │
│ 这是第二/三层推断交还梦者验证的接口                 │
└────────────────────────────────────────────────┘
        ↓
┌─ 段落6：建设性视角（收尾） ─────────────────────┐
│ 以「也许可以这样理解这些梦：」或类似自然句式开头     │
│ 1-2句，读完后有方向感                              │
│ 不以"总之/综上所述/总结"结尾                       │
│ 若触发风险标记，此处用自然语言提示关注              │
└────────────────────────────────────────────────┘
```

> 定调句 + 主导模式 + 情绪基调 + [≥7篇时：时间动态] + 追问 + 建设性视角 = 完整骨架。
> 核心特征不足时不硬凑，在对应位置注明"单篇分析，此维度暂不可用"。

### 写作检查清单

- [ ] 每条描述背后都有对应的图式/情绪数据依据（去第二部分验证）？
- [ ] 没有出现图式编号/光谱数值/评分条/R规则/C1C2S1代码？
- [ ] 第一条能否让梦者说"这说的就是我的梦"？
- [ ] 追问是否从翻译推导而来，不是凭空编造？
- [ ] 如果梦者只读第一部分，是否感觉完整？

## 第二部分：评分与解释

### 定位

为想要深入理解的梦者准备。展示第一部分的判断从何而来——图式数据、翻译链、收敛检查、光谱评分。

### 结构化输出骨架

以下为第二部分**必须出现的板块**，按顺序排列。数据不足的板块标注"数据不足，不做X分析"而非跳过。

```
板块1：综合置信度导语
必含：综合指数X/10 + 五因子得分 + 结论措辞 + R规则适用 + 基线来源

板块2：图式激活数据
必含：图式频率表 + 基线偏离 + 共现聚类 + Gestalt闭合 + 日间残留
≥7篇时追加：收敛预检表（4信号并排 + C2/C3建议区间）

板块3：形成机制翻译
必含：每个闭合模式的完整翻译链（体验域映射→合成→情绪匹配→语境填充→收敛检查）
每个闭合模式独立呈现

板块4：情绪与趋势分析
必含：情感分布全谱
≥7篇时追加：趋势分析（slope + 衰减状态）
<7篇时标注"数据不足，不做趋势分析"

板块5：深层结构推断
必含：三线叠图结果 + 同构判断 + 局限性提示
无传记数据时标注"传记信息不足，不做深层推断"

板块6：光谱评分
必含：六维度评分条 + 综合置信度 + R规则判定

板块7：风险标记
触发时输出风险措辞
未触发时注明原因 + 建议关注方向
```

> 板块1-6 为基础骨架（必出现），板块7 为条件骨架（触发时出现）。
> 板块3/4/5 数据不足时不硬凑，标注"数据不足，不做X分析"。

## 审计方法

第一部分写完后，逐句检查：

1. **证据可追溯**：第一部分的每个描述 → 在第二部分有对应的图式/情绪/趋势证据？→ 无证据则删
2. **技术标记隔离**：第一部分没有出现图式编号/光谱数值/评分条/R规则？→ 全部移至第二部分
3. **定调准确**：第一条能让梦者说"这说的就是我的梦"？→ 否则重写
4. **追问有据**：追问从翻译推导而来？→ 无推导依据的追问删除
5. **硬币两面**：特征呈现了信号+含义？→ 补充缺失面
6. **收尾自然**：以建设性视角收尾，非"总之"？→ 修改收尾
