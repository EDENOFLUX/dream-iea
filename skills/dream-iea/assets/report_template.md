# 三层报告标准格式（Report Template）

> 用于 Step 3 输出。每条推断必附光谱打分（见 `references/scoring.md`）。
> 置信度标记 ■●▲△ 的措辞纪律为硬约束（■ 用「反映/显示」，▲ 用「有限证据提示」）。

## 第一层：图式状态报告（■ 高置信度 · 客观）

仅报图式激活数据，不引入任何心理理论（Step 2a 脚本输出直接引用）。

```
<图式> <频率> (<x/n>) ⚠基线偏离
<组合> 完全闭合×<k>
综合置信度 <标记> [<指数>]
```

## 第二层：理论翻译（● 中置信度，需确认）

每条用「理论 | 标记」起头，末尾附追问句式交还梦者验证：

```
[<理论名> | ●]
<图式模式描述> → <翻译假设>
追问：<交由梦者确认的问题>
```

## 第三层：深层结构推断（▲ 弱信号，需验证）

```
<图式模式与传记线的跨时间同构判断，需梦者验证>
```

## 风险标记

若触发 `references/scoring.md` §七 风险规则，明确写入：
「该图式模式显示高强度且未缓解的情绪负荷，建议考虑与心理健康专业人士交谈。」
不自行诊断，不产出 DSM/ICD 标签。
