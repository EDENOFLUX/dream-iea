# Dream-IEA · 梦境分析 Skill

> © 2026 Luci逻辑喵 (EDENOFLUX) · [CC BY-NC-SA 4.0](../../LICENSE)

基于 IEA（信息元素回溯法）改造的梦境分析框架。核心纪律：**信息元素绝不直接指向心理状态，必须经过意象图式这一中层**。不做「梦到 X = 你在 Y」的象征跳译。

## 铁律（不可违反）

1. **三层映射不可跳步**：梦境叙事 → 信息元素（Step 1）→ 意象图式（Step 2a）→ 心理状态（Step 2b）→ 三线叠图（Step 3）。
2. **元素不直接翻译**：信息元素本身不指向心理状态，必须经过意象图式中层。
3. **输入兼容**：碎片化（词组/短句/跳跃片段）与完整叙事（语法规范）同等对待，走同一解码路径。
4. **不替代临床诊断**：不产出 DSM/ICD 标签；所有心理推断必须交还梦者本人验证。
5. **置信度可追溯**：每个子维度分数及来源（脚本自动 / 分析者赋值）必须明示。

## 操作流程

### Step 0：个人感觉景观校准
建立梦者「感觉基线」——获取近期 1-2 周生活状态、压力事件、长期情绪基调、创伤史（自愿）、文化背景。该基线用于：
- 情感分布的「个人基线」对比（见 `scripts/analyze_dreams.py` 的 `--baseline` 参数）
- Step 3 个人传记线锚定

### Step 1：元素解码
逐篇标注七类信息元素（实体 / 动作 / 空间-关系 / 性质 / 情感 / 抽象结构 / 元元素），**只做识别不做解释**。标注结果存为 JSON（格式见 `assets/dream_diary_template.md`）。

### Step 2a：图式识别（客观层）
运行脚本或手动统计：
- 图式频率（对比基线）
- 图式共现聚类
- 情感分布（全谱，正负对称检测）
- Gestalt 闭合检测（部分闭合≥3 篇 / 完全闭合≥5 篇）
- 日间残留检测（区分当天回放 vs 深层模式）

```bash
python3 scripts/analyze_dreams.py -i <标注JSON> \
    --C2 <理论一致性 1-10> --C3 <时间趋势 1-10> --C4 <传记共振 1-10> \
    --baseline '{"<图式名>":<基线频率>,"<情感名>":<基线频率>}' -o <输出文件>
```
（C2/C3/C4 由分析者按 `references/scoring.md` 规则赋值；analyst 段也可内嵌在 JSON 顶层，无需命令行参数）

### Step 2b：理论翻译（推断层）
对每个闭合图式模式，套用六理论各跑一遍（具身认知 / 连续性假设 / 威胁模拟 / 记忆再激活 / 情绪调节 / 自我组织），交叉校收敛度，用追问句式交还梦者验证。翻译函数与排除项见 `references/theory_translation.md`。

### Step 3：三线叠图
| 线 | 内容 | 来源 |
|----|------|------|
| 图式分布线 | Step 2a 输出 | 梦境标注 |
| 个人传记线 | 生命史关键节点/创伤/转折 | Step 0 + 用户补充 |
| 近期事件线 | 梦前 1-7 天事件时间线 | 每日配注 |

三线交会 = 心理状态推断锚点。

### 输出三层报告
- **第一层**（■ 高置信 · 客观）：图式激活数据，不引入理论
- **第二层**（● 中置信 · 需确认）：理论翻译 + 追问句式
- **第三层**（▲ 弱信号 · 需验证）：图式模式与传记交叉，识别跨时间同构

## 约束与边界

- **日记数量下限**：至少 7 篇，理想 14 篇（单篇不足以建立基线）
- **综合指数为启发式**：权重基于专家判断而非经验校准，不提供统计可靠性保证
- **全情感谱覆盖**：不因「积极」降权（R7），不因「负面」放大
- **风险标记**：反复出现的高强度未缓解图式模式 → 明确建议寻求专业帮助，不自行诊断（规则见 `references/scoring.md` §风险标记）
