# 评分与置信度规范（对齐 LPP 言灵）

> 来源：Dream-IEA 知识包 §四、§六、§七。本文档用于 Step 2a 光谱打分与全报告置信度标注。

## 一、置信度标记 ■ ● ▲ △

| 标记 | 级别 | 触发条件 | 措辞纪律 |
|------|------|---------|---------|
| ■ 强信号 | 高置信 | 完全闭合 + ≥3 理论收敛 + 跨日记稳定 | 用「反映 / 显示 / 表明」 |
| ● 中信号 | 中置信 | 部分闭合 + ≥2 理论 / 或单理论但闭合充分 | 用「可能 / 倾向于 / 指向」 |
| ▲ 弱信号 | 低置信 | 单次或仅单理论，无交叉验证 | 用「有限证据提示 / 不排除」 |
| △ 探索 | 探索性 | 模式有趣但证据不足，不评分 | 仅标注，附局限提示 |

**措辞纪律（硬约束）**：■ 不得用「可能」，▲ 不得用「反映」。错配是报告审计的一票否决。

## 二、光谱打分维度（1-10）

**脚本自动计算：**

| 代号 | 维度 | 1-10 锚点 |
|------|------|----------|
| C1 | 数据充分度 | N=1→1 ｜ N=7→5 ｜ N=14+→10 |
| S1 | 图式闭合度 | 单次1 ｜ 部分闭合(≥3天)5 ｜ 完全闭合(≥5天)9 |
| S2 | 基线偏离度 | 持平1 ｜ 1.5×基线5 ｜ ≥2×基线10 |
| S3 | 情感主导度 | 均布1 ｜ 单一占0.4为5 ｜ 占0.8+为10 |

**分析者按规则赋值（须注明来源）：**

| 代号 | 维度 | 赋值规则 |
|------|------|---------|
| C2 | 理论一致性 | 单理论3 ｜ 2理论5 ｜ 3+理论收敛8 ｜ 高一致10 |
| C3 | 时间趋势 | 无趋势3 ｜ 弱5 ｜ 单调下降/上升清晰10（仅情绪相关推断） |
| C4 | 传记共振 | 无同构0 ｜ 弱4 ｜ 明确同构8 ｜ 强共振10 |

## 三、综合置信度指数（启发式）

```
综合指数 = 0.25·C1 + 0.25·S1 + 0.20·C2 + 0.15·S2 + 0.15·C4
         （C3 仅当推断涉及情绪时纳入，或按 R5 记 5）
```

**映射标记**：综合 ≥7.0 → ■ ｜ 4.0–6.9 → ● ｜ <4.0 → ▲

> 注意：综合指数为启发式指标，权重基于专家判断而非经验校准。其作用是指引谨慎程度，而非量化可靠性。不提供统计可靠性保证。

## 四、IF-THEN 硬规则（优先级高于公式）

| 规则 | 条件 | 动作 |
|------|------|------|
| R1 闭合门槛 | S1 == 不闭合（单次） | 该推断封顶 ▲ |
| R2 数据门槛 | C1 < 5（N < 7） | 综合封顶 ●（不出 ■） |
| R3 高置信触发 | S1 == 完全闭合 且 C2 ≥ 6（≥3理论） | 综合 ≥ ■ |
| R4 单理论封顶 | C2 < 3.4（仅单理论） | 综合封顶 ● |
| R5 情绪趋势中性 | 推断涉及情绪但 C3 未知 | C3 按 5 计 |
| R6 风险降权 | 触发风险标记且梦者否认/无现实锚点 | 该推断降一档，标注「需现实核查」 |
| R7 正面模式同权 | 正面情绪模式（喜悦/敬畏/连接） | 与负面模式同等打分，不降权 |

## 六、约束与边界

- **不替代临床诊断**：不产出 DSM/ICD 标签。持续高强度负面图式模式 → 建议寻求专业帮助
- **需要梦者验证**：第二、三层推断必须经用户确认
- **日记数量下限**：至少 7 篇，理想 14 篇
- **置信度必须可追溯**：每个子维度分数 + 来源（脚本自动/分析者赋值）必须明示
- **综合指数为启发式**：权重基于专家判断而非经验校准，不提供统计可靠性保证
- **全情感谱覆盖**：不因「积极」降权（R7），不因「负面」放大

## 七、风险标记规则

以下模式出现时，明确建议寻求专业帮助（不自行诊断）：
- 反复 {FORCE + CONTAINER破裂 + 恐惧} 且不闭合（连续多日，强度不降）
- 情感分布中恐惧/悲伤占比持续 >50% 且无下降趋势
- 自我否定/消失类图式（同一性否定 + CENTER-PERIPHERY 极端边缘化）密集出现

措辞模板：「该图式模式显示高强度且未缓解的情绪负荷，建议考虑与心理健康专业人士交谈。」
