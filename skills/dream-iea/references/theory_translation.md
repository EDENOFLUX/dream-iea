# 六理论翻译函数

> 来源：Dream-IEA 知识包 §三。本文档用于 Step 2b 理论翻译层。

## 一、入选逻辑（三必要条件，缺一不可）

- (a) 把意象图式当作真实认知基元（不是纯语言修辞）
- (b) 通过图式连接梦内容到清醒心理状态
- (c) 可被实证检验（翻译可证伪，不是玄学）

## 二、六理论

| 理论 | 核心主张 | 翻译方向 | 输入维度 |
|------|---------|---------|---------|
| **具身认知**（Lakoff & Johnson） | 抽象思维建立在身体经验的隐喻映射 | 每个图式 = 一个身体隐喻域，图式激活 = 该域心理操作在运行 | 图式本身 |
| **连续性假设**（Domhoff） | 梦境内容与清醒关注/情绪/社交连续 | 图式激活频率 → 清醒生活中对应身体隐喻的经验频率 | 图式频率 |
| **威胁模拟**（Revonsuo） | 梦的功能是模拟威胁以增强适应性 | 威胁相关图式 + 恐惧 → 威胁检测系统在安全环境模拟运行 | 图式组合内容 |
| **记忆再激活与整合** | 睡眠中海马体重新激活白天编码的记忆 | 日间残留中的图式 → 相关记忆正整合进长时记忆网络 | 残留标记 |
| **情绪调节理论** | REM 睡眠在安全环境重新处理情绪记忆 | 恐惧+图式组合频率随时间递减 → 情绪处理进展中；不递减 → 受阻 | 时间趋势 |
| **自我组织理论**（Kahn & Hobson） | 梦是感觉输入减少时大脑自我组织活动 | 非常见图式共现 → 低约束状态下的认知-情感整合探索 | 组合新奇度 |

## 三、排除的理论

| 理论 | 原因 |
|------|------|
| 弗洛伊德象征 / 梦典 | 跳过意象图式层直接做「梦到 X = Y」，不可证伪 |
| 纯随机激活论 | 否定梦编码了信息——整个翻译层前提不成立 |
| 荣格原型 | 倾向象征而非具身图式落地，即使引用也须通过图式层 |

## 四、翻译操作步骤

```
1. 拆解图式模式 P：频率 / 组合 / 情感 / 时间趋势 / 残留标记
2. 对每个适用于 P 的理论，套用它的映射规则，产出假设 H_T
   （所有相关理论各跑一遍，它们看的是图式模式的不同维度）
3. 收集 {H_T}
4. 交叉校验：多个理论收敛到同一心理状态 → 高置信；冲突/单支持 → 低置信
5. 用 Step 3 近期事件线 / 传记线把方向性假设锚定到具体生活领域
```

## 五、常见图式模式翻译（全情绪谱）

**负面/威胁类：**

| 图式模式 | 翻译 |
|---------|------|
| {CONTAINER + BLOCKAGE} 高频 | 连续性：清醒生活中「被困+受阻」身体隐喻反复激活 |
| {FORCE + CONTAINER破裂 + 恐惧} 闭合 | 威胁模拟 + 连续性 + 情绪调节 → 边界被外力突破的威胁，交叉一致性**高** |
| {VERTICALITY坠落 + LINK断裂} | 具身：向下运动+连接断开的复合隐喻 |
| {SOURCE-PATH-GOAL 迷路} 高频 | 连续性：生活中缺乏清晰路径/方向感 |
| {BALANCE 失衡} 高频 | 具身：对称/均衡维持失效，某领域过度投入 |
| {CENTER-PERIPHERY 被排除} | 连续性：归属感问题，社交/工作中被边缘化 |
| {CONTAINER破裂 + 悲伤} 闭合 | 具身 + 连续性：安全容器破损+悲伤，近期可能经历分离/丧失 |

**正面/积极类（R7 同权，不因「积极」降权）：**

| 图式模式 | 翻译 |
|---------|------|
| {VERTICALITY 飞翔 + 喜悦} 高频 | 具身：向上运动+掌控感隐喻。清醒中拥有自主/胜任体验 |
| {LINK 连接 + 喜悦} 闭合 | 具身：连接/纽带隐喻+正面情感。关系联结被满足 |
| {SOURCE-PATH-GOAL 到达 + 喜悦} 高频 | 具身：路径达成隐喻。目标达成/方向清晰 |
| {CONTAINER 被包裹 + 敬畏} 高频 | 具身：安全容器+敬畏。处于被庇护/崇高的体验中 |
| {BALANCE 平衡 + 喜悦} 闭合 | 具身：均衡维持+正面。生活各领域较均衡 |

**混合/复杂类：**

| 图式模式 | 翻译 |
|---------|------|
| {CONTAINER破裂 + 悲伤 → CONTAINER修复 + 喜悦} 时间序列 | 情绪调节：先丧失后修复轨迹，情绪处理进展中 |
| {VERTICALITY 坠落(恐惧) + VERTICALITY 飞翔(喜悦)} 交替 | 具身：垂直轴双向摆动。清醒中掌控感起伏大 |

## 六、全谱原则

六类情感元素（恐惧/敬畏/厌恶/喜悦/悲伤/愤怒）均须被翻译覆盖。若分析只产出负面假设，检查是否遗漏了日记中的正面/其他情绪片段——这是标注偏差，不是梦只有负面。
